# Practical Moodle Assignment Blueprint — 14 Weeks

**Note:** These are Moodle activity specifications. Creating the actual assignment activities and secure gradebook requires access to your Moodle installation. No students, accounts or grades are stored in this repository.

## Week 1: Practical assignment

**Student task:** Digitize a training farm polygon, record a map screenshot, and explain precision agriculture value.

**Deliverables:** Source files used, exported map or visualization, at least one screenshot or clearly named reproducible GIS artifact, and a brief source/CRS/limitations statement. Students must label synthetic or derived-model data as such.

**Mark out of 10:** Method and correct procedure (2); appropriate input data and CRS (2); correctly labeled outputs (2); reproducibility and source files (2); scientific interpretation, attribution and uncertainty (2). Moodle rubric levels can be 0, 1 and 2 per criterion.

**Submission type:** Moodle Assignment file submissions; optionally online text. Lecturer verifies actual QGIS/KMZ/CSV files.

## Suggested course gradebook design

Use a transparent course scheme approved by the department. An example for discussion is: 14 practical assignments × 10 marks each; one final project counted separately using a published rubric; formative quiz attempts are practice until explicitly included in the official gradebook. Do not silently count browser progress as grades.

## Moodle configuration checklist

1. Import Moodle XML question bank and inspect 3 sample items from separate weeks.
2. Create 14 Assignment activities with unique availability dates and submission instructions.
3. Choose rubric grading (5 criteria × 0–2 points).
4. Make rubric preview visible to students before submission.
5. Create optional formative quizzes per week with explanatory feedback.
6. Test preview attempts with a nonstudent test account and verify Gradebook aggregation.
7. Do not publish student-identifiable data on public GitHub Pages.
