Northern Iraq — Regional Environmental Data Laboratory

This GIS activity uses previously supplied NASA POWER-derived MERRA-2 modeled data instead of fabricated teaching examples. Examine model-grid locations, the July–August 2025 wetness comparison and 2025 monthly air temperatures near Sulaymaniyah.

Provenance limitation: The underlying API responses were not preserved and the values have not been independently revalidated against NASA POWER. These are derived model summaries, not actual station or soil measurements. They must not be used for fertilizer recommendations, farm-level moisture claims or research findings without original-product verification.

QGIS exercise and scientific assessment

  1. Import the wetness CSV through Delimited Text, X = longitude and Y = latitude, source CRS = EPSG:4326.
  2. Display graduated symbols for July, August and July anomaly separately. Compare classifications.
  3. Plot the monthly temperature CSV as a non-spatial table using month and mean_temperature_c.
  4. Create a PDF layout; explain that 28 modeled grid locations are not 28 ground soil-sampling sites.
  5. Document missing original API provenance and distinguish gridded modeled information from station or plot observations.
