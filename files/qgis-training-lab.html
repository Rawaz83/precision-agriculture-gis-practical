Interactive QGIS Training Laboratory

Follow a 75–90-minute practical in QGIS Desktop: identify its interface, import farm observations, work with vector layers, reproject a field, and save a reproducible project. Get instant learning feedback and save personal practice progress in your browser.

Synthetic teaching data only: soil measurements, field boundaries and observation locations are fabricated. This website guides and checks the learning process; it does not run QGIS, verify your GIS files, or upload grades.

Learning outcomes and preparation

  1. Recognize the menu, toolbar, Browser, Layers, canvas and CRS/status bar.
  2. Import the 12-row agricultural soil CSV with X = longitude, Y = latitude, source CRS EPSG:4326.
  3. Recognize and import polygon, line and point GeoJSON datasets.
  4. Distinguish source layer CRS, display/project CRS and exported projected CRS.
  5. Export a field layer to EPSG:32638 and reopen a saved QGIS project.

Task 3 · 20 minutes

Import the CSV and check its coordinate reference

  1. Open QGIS. Select Layer → Add Layer → Add Delimited Text Layer… or Data Source Manager → Delimited Text.
  2. Select demo_soil_samples.csv. Choose CSV file format and Point coordinates.
  3. Check the X, Y and Geometry CRS settings below, then apply these exact settings in QGIS.
  4. Open the attribute table and confirm 12 records, including sample_id, soil_ph and nitrogen_index.
Choose your import settings and select Check.
Why can't I select EPSG:32638 for the original CSV?The source contains WGS 84 longitude/latitude in angular degrees, so EPSG:4326 must be used to interpret its source coordinates. Export to a projected CRS when metric coordinates are needed.

Task 5 · 15 minutes

Change project CRS and export a projected layer

  1. Confirm the original vector source layer is in EPSG:4326 (degrees).
  2. Change only the QGIS project CRS to EPSG:32638 (WGS 84 / UTM zone 38N, metres). Note that the original GeoJSON remains geographic.
  3. Right-click the field layer → Export → Save Features As…, select GeoPackage and output CRS EPSG:32638.
  4. Save to outputs/field_utm38.gpkg. Inspect the new layer CRS and estimate field area in square metres before dividing by 10,000 for hectares. This is an approximate educational area only.
