Interpret with caution

High NDVI can indicate green vegetation, but it does not directly measure disease, fertilizer need or yield. These values are simulated, not satellite observations.

03 · Geographic coordinates

Degrees to DMS converter

Enter a signed latitude or longitude in decimal degrees and display it as degrees, minutes and seconds.

35° 33′ 36.00″

For latitude, valid values lie between −90° and +90°. This tool accepts up to ±180° to also support longitude. Direction (N/S/E/W) depends on whether the number represents latitude or longitude.

Why coordinate reference matters

EPSG:4326 uses geographic degrees. EPSG:32638 uses metres in UTM Zone 38N near Sulaymaniyah. Merely changing the label of a CRS does not reproject existing coordinates.

Academic and data notes

Learning outcomes: Identify spatial feature geometry; inspect field and observation attributes; draw and export a GeoJSON polygon; calculate approximate area; evaluate the NDVI formula; demonstrate coordinate-format understanding.

Source data: GeoJSON training field, original soil sample CSV and tractor-track CSV from this course. All records are synthetic. Vector geometry is represented using WGS 84 longitude/latitude. No spatial interpolation or real agronomic prescription is performed here.

Map data: © OpenStreetMap contributors under the ODbL. This page uses Leaflet 1.9.4 for the interactive map. Leaflet source code is licensed BSD-2-Clause.

Study exercise: Download an exported polygon and open it in QGIS using Layer → Add Vector Layer. Compare this lab's area estimate against a projected metric calculation in EPSG:32638. Document differences, and explain why source geometry accuracy still limits measurement accuracy.
